Odd Twin is an original spot-the-difference game drawn entirely on canvas. Compare two near-identical scenes side by side and click the differences before the timer runs out — with hints when you're stuck, a streak system that rewards clean runs, and WebAudio sound effects. Three hand-crafted levels: the Sunny Breakfast Nook (7 differences), Pip's Garden Shed (9), and The Lantern Library (12).

## Run it

```sh
node serve.ts
```

(serves game/ at http://localhost:8080 — open in desktop Chrome and play; `MAKEFUN_OUTPUT_DIR=out node main.ts` writes the dossier to out/)
